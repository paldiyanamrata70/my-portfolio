# Namrata Paldiya — Developer Portfolio 🎨💼

Welcome to my personal portfolio website! 🎨💼

Showcasing my journey as an MCA graduate and developer, technical skills, and selected projects. Built with React, TypeScript, and modern web technologies, it features interactive UI, smooth animations, and responsive design.

## 🚀 Getting Started

### Prerequisites

- Node.js (version 18 or higher)
- npm or yarn

### Installation

Clone the repository:

```sh
git clone https://github.com/paldiyanamrata70/my-portfolio.git
cd my-portfolio
```

Install dependencies:

```sh
npm install
```

Start the development server:

```sh
npm run dev
```

Open http://localhost:8080 in your browser.

## 🛠️ Build for Production

```sh
npm run build
```

## 👁️ Preview Production Build

```sh
npm run preview
```
